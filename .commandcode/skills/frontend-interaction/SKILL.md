# Frontend Interaction

Follow `DESIGN_SYSTEM.md`.

- Use motion to communicate state or continuity.
- Prefer subtle transitions.
- Respect reduced-motion preferences.
- Preserve keyboard navigation and focus.
- Keep mobile performance in mind.
- Reuse existing UI patterns.
- Do not add decorative effects without a clear design reason.

Never weaken security, data integrity, or architecture for visual effects.
